# 🚀 AIPICK (아이픽) - 맞춤형 AI 추천 및 교육 플랫폼

## 📖 프로젝트 소개
**AIPICK(아이픽)**은 사용자에게 꼭 맞는 AI 학습 경로를 탐색하고 추천해 주는 종합 AI 플랫폼입니다. 최신 AI 도구 추천부터 국비지원 부트캠프, 추천 강의 및 도서 정보, 그리고 실시간 AI 소식까지 한곳에서 확인할 수 있습니다.

## 👥 팀원 및 역할 분담
* **노성겸 (본인)**: 마이페이지, 회원가입, 로그인 기능 구현 및 전체 시스템 아키텍처(ER-D, Flowchart) 설계
* **박진우**: AI 교육(부트캠프, 강의/도서) 페이지, 관리자 페이지 구현 및 시스템 아키텍처 설계
* **장준하**: AI 소식 페이지 구현
* **이규민**: AI 추천, 상세 페이지, 사용자 후기 및 커뮤니티 구현 (담당 기능 통합)

## 💻 주요 기능 상세

### 1. 🔐 회원가입, 로그인 및 마이페이지 (담당: 성겸)
* **회원가입/로그인**: 필수 및 선택 약관 동의(이메일 수신 동의 등) 기능을 구현하였으며, 입력 항목 누락 및 비밀번호 조건(영문/숫자/특수문자 조합 10~16자) 불충족 시 토스트 알림을 통해 유효성 검사를 수행합니다.
* **마이페이지**: 닉네임, 이메일, 비밀번호 변경 기능과 이메일 수신 동의 체크박스(AJAX 방식)를 구현하였으며, 회원 탈퇴 시 DB에서 정보가 삭제되도록 설계했습니다.

### 2. 📊 관리자 페이지 (담당: 진우)
* **대시보드 및 통계**: 그룹 함수 쿼리를 활용해 전체 사용자, 관리자, AI 도구 수 등을 시각화하여 한눈에 파악할 수 있습니다.
* **데이터 관리 및 검색**: 광범위한 실시간 검색(ID, 이메일, 닉네임 등)을 지원하며, 모달창을 통해 사용자 정보 및 문의 답변을 페이지 이동 없이 즉각적으로 수정 및 관리할 수 있습니다.

### 3. 🎓 AI 교육 (담당: 진우)
* **국비지원 부트캠프 & 추천 강의/도서**: AI 관련 교육 사이트와 영상을 언어, 분야, 교육 기간 등에 따라 필터링하고 정렬할 수 있는 기능과 구매/신청 사이트 외부 링크 이동 기능을 제공합니다.

### 4. 📰 AI 소식 (담당: 준하)
* **뉴스 피드**: 실시간 급상승 AI 소식, 주간 핫한 소식, 테마별(대화형 챗봇, 미디어, IoT 등) AI 최신 뉴스를 정적 필터링을 통해 랭킹 순으로 제공합니다.

### 5. 🤖 AI 추천 및 커뮤니티 (담당: 규민) 
* **맞춤형 AI 추천**: 테마별, 최근 출시/업데이트, 사용자 리뷰 기반(조회수, 좋아요 랭킹)으로 AI를 추천합니다.
* **상세 페이지 및 후기**: 각 AI의 핵심 정보와 기술적 배경을 제공하며, 로그인한 유저에 한해 후기를 작성할 수 있는 시스템을 구축했습니다.

## 🐛 트러블슈팅 (Bug History)

| 문제 상황 | 원인 | 해결 방법 |
| :--- | :--- | :--- |
| **JS 작동 오류 (성겸)** | 자바스크립트 파일 경로에 오타(`singup.js`)가 있어 비밀번호 확인 버튼이 작동하지 않음 | 경로 파일명을 `signup.js`로 수정하여 기능 정상화 |
| **Google 로그인 오류** | Firebase와 Google Auth Code의 이중 인증 처리로 인한 서버 충돌 발생 | Firebase 연동만 유지하여 소셜 로그인 정상 구현 |
| **DB 연결 실패** | `users` 테이블의 auto_increment 정수형 ID 대신 문자열 `user_id`를 받아옴 | 쿼리 변수를 `$SESSION['user_id'] ?? 0`으로 수정하여 데이터 연결 성공 |
| **UI Grid 공백 발생** | PHP `foreach` 문 안의 `<?php ... ?>` 태그가 렌더링 시 의도치 않은 공백으로 인식됨 | PHP 태그로 전체 코드를 감싸는 형식으로 변경하여 레이아웃 정렬 |
| **CSS 미적용 (준하)** | 서버 내 CSS 파일에 읽기 권한이 부여되지 않음 | 올바른 권한이 부여된 CSS 파일로 교체 및 복사하여 해결 |

## 📈 평가 및 향후 개선 사항
* **인증/인가**: 현재 로그인 편의성은 높으나, 향후 '자동 로그인' 기능과 가입 시 입력 항목 확장이 필요합니다.
* **관리자 시스템**: 데이터가 방대해질 경우를 대비해, 클라이언트 측 검색이 아닌 서버 측 검색 및 페이징 처리를 도입해야 합니다.
* **콘텐츠 자동화**: 하드코딩된 AI 소식 데이터를 상용 뉴스 API와 연동하여 자동 수집(DB화)하는 시스템으로 고도화할 계획입니다.
* **커뮤니티 고도화**: 공정성을 위해 1인 1후기 제한을 두고, 문의하기 게시판에 이미지 첨부 및 수정 기능을 도입할 예정입니다.
